# International Freight Mod

The International Freight Mod (working title) is a Minecraft mod which adds freight trains, planes, trucks, and a mail system, similar in style to and compatible with Jonathan Ho’s Minecraft Transit Railway passenger transit mod (not affiliated).

The mod is still a work-in-progress and work has now begun. We are considering setting up social media accounts, and, if so, you can follow us there. For the time being, we’ll keep everyone updated on the Canned Water Studios Discord Server and occasionally on the Minecraft Transit Railway Discord Server.

The current contributors to this project are GJAKaina, Mabatogo and Some1Fox. If you would like to contribute to the project, please contact us at info@cannedwaterstudios.com or message one of us on the Discord server (linked above).
