# International-Freight-Mod

The International Freight Mod (working title) is a Minecraft mod which adds freight trains, planes, trucks, and a mail system, similar in style to [Jonathan Ho](github.com/jonafanho)’s [Minecraft Transit Railway](github.com/Minecraft-Transit-Railway/Minecraft-Transit-Railway) passenger transit mod (not affiliated).

The mod is still a work-in-progress and work has now begun. We are considering setting up social media accounts, and, if so, you can follow us there. For the time being, we’ll keep everyone updated on the [Canned Water Studios Discord Server](https://discord.gg/D4uKaeU5Tv) and occasionally on the [Minecraft Transit Railway Discord Server](https://discord.gg/TYnpQKH6dE).

The current contributors to this project are GJAKaina and Mabatogo. Neither of us are very skilled at modeling or Java development. If anyone is willing to help it would be greatly appreciated. Please contact us at cannedwaterstudios@proton.me or message one of us on the Discord server (linked above).
